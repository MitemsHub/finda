# Reference Teardown: Miva Open University

> **Essence:** Nigeria's online-first university. Because the core buyer anxiety is *"is this a real, respected degree?"*, the entire site is **trust engineering**: the NUC accreditation badge front-and-center, maiden-convocation photography as proof of real graduates, clear faculties, and **transparent per-session tuition (₦ and $)**. Aspirational-but-credible ("Accessible. Flexible. Credible.").
> **Source:** https://miva.edu.ng · analyzed 2026-07-08 · confidence: mixed (live homepage capture)

> ⚖️ **Copying-line status:** PASS — principles only. No logos/photography/copy reproduced.

## 1. Design Philosophy
Miva's job is to convert skeptics who equate "online" with "not real." Every section answers a credibility objection: *licensed by the NUC* (regulator authority), *maiden convocation* (real graduates exist), *named faculties + specific programmes* (academic substance), *transparent tuition* (no hidden cost anxiety), and dual-currency pricing (diaspora reach). It is aspirational and warm but anchored in proof.

## 2. Typography Breakdown
- **Family (inferred):** clean, professional sans; confident display headings ("Be Outstanding with a Miva Degree").
- **Hierarchy:** large aspirational hero statements + rotating value props (Accessible / Flexible / Credible), clear faculty card titles, prominent tuition figures.

## 3. Color Palette
- Institutional, trustworthy palette (brand primary + clean neutrals) — education leans toward credible/competent tones (cf. Coursera's trust-blue lesson). Photography of real people/events supplies warmth.

## 4. Spacing Scale
- Comfortable, sectioned; faculty cards in a clear grid; generous separation between credibility beats (accreditation → convocation → faculties → tuition).

## 5. Grid System
- Capped content; **faculty card grid** (5–6 schools, each with programmes + tuition + Learn More); rotating hero; logo/badge placements for accreditation.

## 6. Motion Language
- Rotating hero slides (01/02/03), gentle reveals. Restrained — trust content leads, not spectacle. Respect reduced-motion.

## 7. Interaction Patterns
- Dual CTAs done right: **"Apply Now"** (high intent) + **"View Programmes"** (research intent) for two funnel stages. Faculty cards → detail pages. Accreditation badge links to the regulator (verifiable authority).

## 9. Reusable Ideas (as principles)

- **Show real outcomes as proof** (convocation photos = "graduates exist") → [`17`](../17-LANDING_PAGE_DESIGN.md).

## 10. Things to Avoid
- Rotating hero carousels can bury the primary message + hurt LCP — ensure the key value/CTA is always visible + performant ([`35`](../35-PERFORMANCE.md), [`17`](../17-LANDING_PAGE_DESIGN.md)).
- Accreditation/outcome claims **must be true and verifiable** (education is high-trust; false claims are serious, Art. III).
- Heavy scaled photography needs image optimization ([`35`](../35-PERFORMANCE.md)).
- Cookie-consent walls (present here) shouldn't obstruct core content/accessibility ([`22`](../22-ACCESSIBILITY.md)).

## 11. How to Recreate This Style Without Copying
1. Identify the buyer's **core fear** (for credentials: legitimacy) and answer it *first* with **verifiable authority proof** (your accreditation/certifications).
2. Show **real outcomes** (graduates, alumni, results) as proof — your own, honest.
3. Make **pricing transparent** (and multi-currency if you serve a diaspora).
4. Use **two-stage CTAs** (research vs. commit).
5. Keep hero **performant** and the primary value always visible.
6. Diverge with your own palette, photography, and voice.
